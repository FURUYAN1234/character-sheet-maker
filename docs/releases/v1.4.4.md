# Character Sheet Maker v1.4.4

## What's New / 更新内容

- Image-to-prompt analysis records visible identity details for hair, face, clothing layers, and accessories in a structured form, then assembles a text-only reconstruction prompt with identity-preservation priorities. Hidden or uncertain details are not invented. / 画像から見える髪・顔・衣装の重なり・装飾品などを構造化し、人物の同一性を優先するテキスト専用プロンプトを作成します。隠れた部分や不確かな特徴は創作しません。
- The prompt panel now explains directly below the text whether it was restored from embedded PNG design data or inferred by AI from an imported image. / プロンプト欄直下に、PNG内の設計データから復元したのか、読み込んだ画像からAIが推定したのかを明示します。
- Regeneration uses the prompt as text without attaching the source image. An inferred prompt is not the original prompt, and the same image is not guaranteed. / 再生成は元画像を添付せず、プロンプトのテキストだけを使います。推定プロンプトは元のプロンプトではなく、画像の完全一致も保証しません。
