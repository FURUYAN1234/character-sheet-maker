# Character Sheet Maker v1.4.0

## What's New / 更新内容

- Prompt saving now downloads a named UTF-8 `.txt` file directly; no browser-only saved-prompt history is shown. / プロンプト保存は名前付きUTF-8 `.txt` ファイルを直接ダウンロードし、ブラウザ内だけの保存履歴は表示しません。
- The prompt controls remain on one row: filename input, Save, then the rightmost Text Copy button. / プロンプト操作は一行で、ファイル名入力、保存、右端のテキストCopyの順に配置しています。
- Added focused regression checks for the direct download and control ordering. / 直接ダウンロードとボタン順序の回帰チェックを追加しました。
