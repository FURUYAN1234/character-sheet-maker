# AI Character Sheet Maker v1.5.2

## English

### What's New

- [models] Added GPT-6.1 Terra to the OpenAI text selector and downward fallback route, with standard API prices of $1 input and $5 output per million tokens.
- [defaults] Kept GPT-6.1 Sol as the default. Image-to-prompt analysis and image generation retain their separate model routes.

## 日本語

### 更新内容
