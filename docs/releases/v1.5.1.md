# AI Character Sheet Maker v1.5.1

## English

### What's New

- [vision] Migrated image-to-prompt analysis to GPT-6 Luna while retaining structured identity extraction, completeness checks and text-only image reconstruction.
- [models] Removed retiring GPT-4 models from active text choices and fallback routes.
- [json] Image identity analysis explicitly requests JSON output before validating the complete character schema.

## 日本語

### 更新内容

- [vision] 画像からプロンプトを作る解析をGPT-6 Lunaへ移行し、人物特徴の構造化抽出、応答の完了確認、文章だけによる画像再構成を維持しました。
- [models] 終了予定のGPT-4系を文章の選択肢とフォールバックから除外しました。
- [json] 人物特徴の解析でJSON形式を明示的に要求し、完全な人物スキーマを検証してから採用します。
