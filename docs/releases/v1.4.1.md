# Character Sheet Maker v1.4.1

## What's New / 更新内容

- Representative-character presets now provide distinct complete profiles, including name, personality, catchphrase, and dialogue. / 代表キャラプリセットごとに、氏名・性格・口癖・台詞まで異なる完成プロフィールを用意しました。
- **キャラ固定** preserves the selected character's identity. While fixed, the single preset row changes only the visual theme; **固定解除** restores full-character preset application. / **キャラ固定**中は人物の核を維持し、一列のプリセットで見た目テーマだけを変更できます。**固定解除**で完全な代表キャラプリセットへ戻ります。
- The OpenAI random-text request now includes speech style, era, and role context, reducing repeated generic dialogue. / OpenAIのランダムテキスト生成に話し方・時代・役割を渡し、似通った台詞を減らしました。
- Added regression coverage for preset profile diversity, lock/theme behavior, OpenAI context, and the one-row preset toolbar. / プリセットの多様性、固定テーマ、OpenAIコンテキスト、一列プリセット表示の回帰テストを追加しました。
