# AI Character Sheet Maker v1.6.3 / AIキャラクターシートメーカー v1.6.3

## Changes / 更新内容

- Choose and edit facial features individually, including outline, jaw, eye spacing, nose, philtrum, mouth and asymmetry. Apply one of four face presets or randomize the face while keeping the hairstyle, outfit and locked fields. / 輪郭・顎・目の間隔・鼻・人中・口・左右差などを個別に選択・自由入力できます。顔プリセット4種と、髪型・衣装・ロック済み項目を保つ「顔だけランダム」を追加しました。
- Set shoulder width, torso-to-leg proportions and standing posture. Newly saved form-generated PNGs restore both the design prompt and editable form settings. Older embedded prompts remain readable. / 肩幅、胴と脚の比率、立ち姿と重心を指定できます。この版でフォームから生成・保存したPNGを開くと設計プロンプトとフォーム設定を復元し、従来のPNGからも埋め込みプロンプトを読み込めます。
- Pick a different art style with matching linework, coloring and shadows. Explicit style directions take priority. / 「画風をおまかせ」は現在・直前と異なる画風を選び、線・塗り・陰影をまとめて切り替えます。具体的な画風の指示を優先します。
- MCP supports the new appearance fields and exposes eight art-style sets through `character_style_options`. Set `profile.artStyle` to a preferred style or `おまかせ` for automatic selection. / MCPから顔・身体の新項目を指定できます。`character_style_options` で8種類の画風セットを取得し、`profile.artStyle` に希望する画風または「おまかせ」を渡せます。

## Verification / 検証

- Checked face and body controls with real OpenAI and Gemini image generation. Verified automatic and explicit art styles through the normal Gemini MCP route, including PNG metadata and a side-by-side review of the images. / OpenAIとGeminiの実生成で顔・身体の指定を確認しました。Geminiの通常MCP経路では、おまかせと画風指定を実行し、出力画像とPNGの設定を照合しました。
- Checked the desktop and narrow layouts, A/B comparison, legacy and current PNG loading, and the production build. Image model adherence varies across outputs. / 通常幅・狭幅の画面、A/B比較、旧形式・現行PNGの読み込み、本番ビルドを確認しました。画像モデルによる指定の反映度には出力ごとの差があります。
