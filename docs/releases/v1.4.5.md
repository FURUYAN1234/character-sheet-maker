# Character Sheet Maker v1.4.5

## What's New
- [gpt-model-menu] Select all 11 GPT fallback models with Astra first and GPT-6.1 Sol as the default. Field generation and text gacha begin at the chosen model and fall back only downward; prices and attempted/adopted model status are displayed.
- [completion-guard] GPT-6 and GPT-5.6 use compatible output parameters. Authentication, refusal and incomplete responses stop further fallback requests.

## 更新内容
- [gpt-model-menu] Astraを最上位、GPT-6.1 Solを初期選択として全11モデルを選択可能にしました。項目生成・テキストガチャは選択モデルから下位へ切り替え、料金と試行・採用モデルを表示します。
- [completion-guard] GPT-6・GPT-5.6の出力設定に対応し、認証失敗・拒否・途中終了では追加のフォールバック呼び出しを停止します。
