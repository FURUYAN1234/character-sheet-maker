# Character Sheet Maker v1.4.3

## What's New / 更新内容

- Generated PNGs now carry versioned `furu.character_sheet` design metadata for exact prompt restoration; no API key is stored. / 生成PNGにバージョン付き `furu.character_sheet` 設計メタデータを保存し、プロンプトを正確に復元できます。APIキーは保存しません。
- The result region accepts PNG and JPG/JPEG. Metadata-free images are displayed immediately and analyzed by the selected provider to create a clearly labeled, detailed estimate. / 生成結果領域でPNGとJPG/JPEGを読み込めます。設計データのない画像はすぐ表示し、選択中のAIが詳細な推定プロンプトを作成します。
- Regeneration sends the displayed restored or inferred prompt as text for a fresh image. It does not use the imported image as a reference and does not overlay unrelated current-form profile text; the result panel states this source. / 再生成は表示中の復元・推定プロンプトをテキストとして新規画像生成へ送ります。読み込み画像を参照画像にはせず、現在フォームの無関係なプロフィール文字も重ねず、結果欄に出所を明示します。
- Added visible import, analysis-progress, completion, and failure messages in both the top status line and result panel. / 読み込み・解析進捗・完了・失敗を画面上部のステータス行と結果欄へ表示します。
