AI Character Sheet Maker v1.6.3のMCP導入

Windowsで起動する

  1. 公式GitHubリポジトリのソースZIPを展開し、Node.js 22.16以降を用意します。
  2. Launch-MCP.cmd を開き、「Start MCP and open the application」を選びます。ウィンドウを切り替えるときは、作業を保存してから停止してください。
  3. 画面の「MCP接続」から接続できます。Codexからは実行チャットの内蔵ブラウザーで character_connection が返す一時URLを開くと自動接続します。

Codexに登録する

展開先の絶対パスを指定します。起動バッチで新版に切り替えた後も、この登録先から新しい管理版を選びます。

codex mcp add character-sheet-maker -- node "C:\path\to\character_sheet\Launch-Codex-MCP.mjs"

通常のアプリ画面でAPIを接続し、character_capabilities の接続状態と providerReady を確認します。APIキーはチャットや設定ファイルの引数に入れません。

生成して次のアプリへ渡す

character_generate_sheet で開始し、character_job_get で完了と成果物を確認します。停止は character_job_cancel で依頼できます。

input.profile に顔や体の特徴を文字列で指定できます。省略した項目は現在のフォームを引き継ぎます。指定を解除する場合は「おまかせ」を渡します。

  • 顔の形と特徴 faceOutline（輪郭）、jawShape（顎）、eyeShape（目の形）、eyeSpacing（目の間隔）、browShape（眉）、noseShape（鼻）、philtrumLength（鼻から上唇までの距離）、mouthShape（口）、faceDetails（ほくろや左右差）
  • 体のシルエットと立ち姿 shoulderWidth（肩幅）、torsoLegRatio（胴と脚の比率）、standingPosture（立ち姿・重心）

画風を決める

character_style_options で画風と線・塗り・陰影の候補を取得できます。この操作は画像を生成しません。

  • 画風の指定があれば、指定どおりの名称または自由記述を input.profile.artStyle に渡します。
  • 画風を任された場合は "artStyle": "おまかせ" を渡します。現在と直前の画風を避け、線・塗り・陰影などをまとめて選びます。
  • 方向性で仕上がりが変わる場合は、候補から数案を示して相談できます。artStyle を省略すると現在の画風を引き継ぎます。

返ったPNGパスは、漫画アプリの「素材を取り込む」MCPツールへ渡せます。

制作スキルZIPを取得。展開した character-sheet-mcp フォルダーをCodexのスキル用フォルダーに配置し、SKILL.md が見えることを確認します。

更新する

起動バッチの「Check for an application update」または「Update the application」を使います。更新候補は別の場所に展開・ビルドされ、成功した版だけが次回起動の対象になります。
