## AI Character Sheet Maker v1.3.8 / AIキャラクターシートメーカー v1.3.8

### What's New / 更新内容
- OpenAI image generation now starts with `gpt-image-2.5-sunburst` at `xhigh`. / OpenAI画像生成は `gpt-image-2.5-sunburst` の `xhigh` から開始します。
- A non-policy error falls back once to `gpt-image-2` at `high`. / ポリシー以外のエラー時は `gpt-image-2` の `high` へ一度だけフォールバックします。
- Content-policy blocks do not make a second image request. / コンテンツポリシーによる拒否では二度目の画像リクエストを行いません。
- The API gate starts with OpenAI selected; entering a Gemini key preserves the Nano Banana route. / APIゲートはOpenAIを初期選択し、Geminiキー入力時はNano Banana経路を維持します。
